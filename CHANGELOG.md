## Правила
- Запись добавляется **после каждой выполненной задачи** роадмапа. В заголовке ID задачи, например `1.F1`.
- Новые записи сверху.
- Если задача опирается на изменение API, в поле **API** ставится ссылка на запись в [CHANGELOG бэкенда](../task-management-backend/CHANGELOG.md) и перечисляются обновлённые файлы в `src/api`.
- Поле **Маршруты** — новые или изменённые URL страниц (важно для ссылок из писем и Telegram).
- Поле **Конфигурация** — новые или изменённые `VITE_*` переменные. Они же добавляются в `.env.example`.
- Поле **i18n** — какие разделы переводов добавлены (с Ф2).
- Если чего-то нет, пишется «—».

## 2026-10-17 — Ф1 (фронт): сессии, вход по коду, приглашения, выход из пространства; основа i18n, ребрендинг, без заглушек
**Фаза:** Ф1 (+ часть Ф2) · **Тип:** исправление, новая функция, UI
**Что изменено:**
- **1.F1** HTTP-клиент (`api/client.ts`):
  - включён `withCredentials`;
  - при 401 выполняется один общий тихий `POST /auth/refresh` и запрос повторяется;
  - если сессию продлить нельзя, показывается «Сессия истекла» и открывается `/login`;
  - ошибки приводятся к `ApiError { status, code, message }`, сообщение берётся на русском по коду;
  - при загрузке приложения без токена сессия восстанавливается из httpOnly-cookie (`main.tsx`).
- **1.F2** Выход вызывает `POST /auth/logout` и очищает все сторы (`lib/session.ts → signOut`). Удаление аккаунта очищает локальную сессию.
- **1.F3** Захардкоженный адрес прод-бэка в `api/auth.ts` убран. OAuth идёт на `VITE_API_URL` (или на свой origin), API по умолчанию — `/api/v1` (same-origin, ADR-003).
- **1.F4** Новая публичная страница `/invites/:token`:
  - показывает, кто и куда приглашает, с какой ролью и до какого числа;
  - «Войти и принять» или «Зарегистрироваться» с подставленным адресом и возвратом на страницу;
  - обрабатывает случаи «приглашение на другой адрес» (с кнопкой «Сменить аккаунт»), «истекло» и «уже принято».
- **1.F5** Вход и регистрация по коду на email через `/auth/email/otp/*`. Генерация случайного пароля удалена. При регистрации спрашиваются фамилия и имя. Вкладки «Вход» и «Регистрация», параметры `?next=` и `?email=`. Для OAuth адрес возврата запоминается до редиректа.

- **2.F2 (основа)** Подключён i18next. Ключи перевода — сами русские строки (gettext-стиль), поэтому интерфейс сразу на русском, а английский потом добавится одним файлом. Добавлены `lib/plural.ts` (русские формы множественного числа), `lib/dates.ts` и `lib/translit.ts`.

Переведены страница входа, онбординг (без `app.plane.so`; идентификатор пространства транслитерируется с кириллицы: «Ректорат» → `rektorat`), шапка, сайдбар, иконочная панель, настройки пространства и проекта, главная.
